2. 📁 database/ - Database Files Explanation

database/schema.sql
Purpose: Defines the normalized MySQL relational database structure.
Details: Creates 15 3NF normalized tables (users, admin, addresses, brands, categories, subcategories, products, product_variants, cart, cart_items, wishlist, orders, order_items, payments, reviews). Enforces Primary Keys, Foreign Keys, cascading rules, and performance indexes.
database/seed_data.sql
Purpose: Populates initial mock dataset into MySQL.
Details: Inserts 10 Main Categories, 30 Subcategories, 15 Brands, 100 Products with prices, discounts, ratings, variants (sizes, colors, stock), user accounts, and reviews for demonstration.

3. 📁 backend/ - Java MVC Backend Files Explanation

backend/pom.xml
Purpose: Maven Project Object Model configuration.
Details: Declares external dependencies: Jakarta Servlet API 6.0, MySQL Connector/J 8.3, Google Gson 2.10 (JSON parsing), jbcrypt 0.4 (password security), and configures the WAR plugin build.
backend/.../util/DBConnection.java
Purpose: JDBC Connection Factory Utility.
Details: Loads MySQL JDBC driver dynamically into memory via Class.forName("com.mysql.cj.jdbc.Driver") and opens SQL Connection sessions via DriverManager.getConnection(...).
backend/.../filter/CorsFilter.java
Purpose: Cross-Origin Resource Sharing Security Filter.
Details: Uses @WebFilter("/*") to intercept HTTP requests/responses, attaching headers like Access-Control-Allow-Origin: * and handling preflight OPTIONS requests for React client integration.
backend/.../dao/impl/ProductDAOImpl.java
Purpose: Product Data Access Object Implementation.
Details: Contains JDBC SQL queries using PreparedStatement to perform multi-criteria product filtering (category, brand, price slider, gender tag), sorting, pagination, and admin CRUD operations.
backend/.../dao/impl/UserDAOImpl.java
Purpose: User Authentication & Profile DAO.
Details: Handles user registration, login authentication, and password updates. Secures passwords using BCrypt encryption (BCrypt.hashpw(...)).
backend/.../servlet/ProductServlet.java
Purpose: Product Controller REST Servlet.
Details: Mapped to @WebServlet("/api/products/*"). Overrides doGet() to parse HTTP query parameters, call `ProductDAO`, and return JSON data to the React view using Google Gson.
backend/.../servlet/AuthServlet.java
Purpose: Authentication Controller Servlet.
Details: Handles /api/auth/login, /api/auth/register, and /api/auth/logout endpoints. Manages HTTP sessions using req.getSession(true).

4. 📁 frontend/ - React.js Frontend Files Explanation

frontend/src/App.jsx
Purpose: Main Application Component & Router Configuration.
Details: Configures 13 client routes using react-router-dom (`Routes`, `Route`), wraps the tree in `AuthProvider`, `CartProvider`, and `WishlistProvider`, and renders persistent `Navbar` and `Footer`.
frontend/src/services/api.js
Purpose: Network API Service Layer.
Details: Dispatches `fetch()` API calls to Java Servlets `/api/*` endpoints. If server/database is offline, try-catch fallback filters data locally from `data/products.js`.
frontend/src/context/CartContext.jsx
Purpose: Global Cart State & Coupon Engine.
Details: Manages item additions, size/color variant selections, quantity modifications, `localStorage` persistence, and coupon validation (`STUDENT10` applying 10% discount).
frontend/src/pages/Products.jsx
Purpose: Product Catalog Page.
Details: Combines search, multi-criteria sidebar filters, array sorting, responsive grid, and pagination.
frontend/src/pages/Checkout.jsx
Purpose: Order Checkout Page.
Details: Manages delivery address forms, payment gateway selection (UPI, Credit/Debit Card, COD), order summary calculations, and confirmation modals.
frontend/src/pages/AdminDashboard.jsx
Purpose: System Admin Panel.
Details: Features sales & order metrics cards, tabbed product CRUD (Add, Edit, Delete products), category manager, and order status update controls (`PROCESSING` -> `SHIPPED` -> `DELIVERED`).
