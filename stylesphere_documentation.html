Project Name: StyleSphere
Type: Full-Stack Student Fashion E-Commerce Web Application
Technology Stack: React.js (v19), Java Servlets (6.0), JSP, JDBC, MySQL 8.0, HTML5, CSS3, ES6 JavaScript

1. Executive Summary

StyleSphere is a modern student fashion e-commerce platform inspired by Myntra and Amazon. It features 13 pages, full filtering, search, shopping cart, coupon codes, checkout, order tracking, and an admin dashboard.

2. Core Architecture & Concepts

2.1 What are Java Servlets?

A Java Servlet is a server-side component that handles client HTTP requests, executes business logic, queries database via JDBC, and returns JSON or HTML responses.

Client (React) ---> HTTP Request ---> Tomcat Servlet Container (doGet / doPost) ---> JSON Response

2.2 What is JDBC?

JDBC (Java Database Connectivity) connects Java code to MySQL. PreparedStatement pre-compiles queries and prevents SQL injection attacks.

2.3 What is MVC Architecture?

Model: POJO classes (Product.java, User.java) & DAO database logic.
View: React.js single-page user interface.
Controller: Java Servlets (ProductServlet.java, AuthServlet.java).

3. Top 10 Technical Interview Questions

Q1: Why use PreparedStatement over Statement in JDBC?
Answer: PreparedStatement pre-compiles SQL queries and escapes input parameters, preventing SQL Injection vulnerabilities and improving query execution performance.
Q2: What is the DAO Pattern?
Answer: The Data Access Object pattern separates database operations from application logic using interfaces, allowing database changes without breaking business logic.
Q3: How does React Context API replace Redux?
Answer: React Context API manages global state (cart, user login) across components without prop-drilling or external dependency boilerplate.
Q4: How is password security handled?
Answer: Passwords are hashed using BCrypt with unique salt generation (BCrypt.hashpw(password, BCrypt.gensalt())) before storing in MySQL.
Q5: What is CORS and how was it resolved?
Answer: CORS blocks cross-domain API calls. It was resolved by implementing CorsFilter.java in Java to append Access-Control-Allow-Origin: * headers to responses.
